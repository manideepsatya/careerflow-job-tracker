# CareerFlow Job Tracker

CareerFlow is a backend application for tracking job applications.

## Current Features

- Create a job application
- View all job applications
- View one application by ID
- Update an application
- Delete an application
- Health check endpoint

## Tech Stack

- Python
- FastAPI
- Pydantic
- Git
- GitHub

## Current Status

The project currently uses temporary in-memory storage.

PostgreSQL database integration will be added next.
